# Mini-Project-7
Techincal Summary-
Electricity Consumption Forecasting Using RNN is a deep learning project that predicts future electricity demand using historical electricity consumption data. It uses Python, TensorFlow/Keras, Pandas, and NumPy to preprocess data and train a Recurrent Neural Network (RNN) model. The model learns patterns from past electricity usage and forecasts future consumption. The results are evaluated using performance metrics and visualized through graphs, helping improve energy management and planning.
